# خلف خلاف!

لعبة قعدة عربية لـ3–12 لاعب، بوضع تمرير الهاتف أو غرفة بأجهزة متعددة وشاشة جمهور مستقلة. وضع «اثنين مختلفين» يبدأ من 8 لاعبين.

```sh
npm install --legacy-peer-deps
npm run dev
```

افتح `http://localhost:3000`. للأجهزة المتعددة استخدم عنوان جهاز المضيف المتاح للهواتف على نفس الشبكة، وافتح رابط البروجكتر منفصلًا. بعد كشف جميع البطاقات يمر كل لاعب مرة بالسؤال ومرة بالجواب. «أجّل المواجهة» ينقلها لآخر الدور. انتهاء المؤقت إشارة للمجموعة؛ المضيف يضغط «تم، اللي بعده» بعد انتهاء الجواب.

`npm test` لاختبار قواعد اللعب والخادم، و`npm run lint` و`npm run build` لفحص المشروع. الاسم والشعار النصي في `src/game/brand.ts`. اللعب يستخدم البنك الموجود بدون طلبات ذكاء اصطناعي.

تحديث الصفحة يعيد المباراة في التبويب نفسه. على الهاتف الواحد تُحفظ المباراة داخل التبويب وتبقى الحماية من المشاهدة بالخطأ؛ فحص ذاكرة المتصفح على الهاتف المشترك يتيح رؤية الحالة. الغرف المتعددة في ذاكرة خادم واحد، وتنتهي بعد ساعتين من عدم النشاط أو عند إعادة تشغيل الخادم. رابط الجمهور يعطي عرضًا عامًا لمن يعرف رمز الغرفة، بدون رموز الدخول أو كلمات اللاعبين قبل الكشف. عند الاستضافة استخدم HTTPS/WSS، واضبط `TRUST_PROXY=1` فقط خلف وسيط موثوق يضبط الترويسات. إدارة البنك اختيارية وتتطلب `ADMIN_PASSCODE` مخصصًا.
